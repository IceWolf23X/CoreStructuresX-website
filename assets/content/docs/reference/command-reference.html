Start sender rules

A player may omit location; the command uses the player's block position and snaps yaw to a cardinal facing. Console must supply world, integer x/y/z and NORTH, EAST, SOUTH or WEST. actionbar requires a player sender.

Mode overrides

automatic/auto and proximity/player_proximity/player-proximity <radius> are accepted. The optional word type is accepted before the mode. Overrides are stored on the instance and do not edit structure.yml.

Lifecycle safety

Pause does not make reload safe. Stop is rejected while an active or finalizing job exists. Clear-footprint applies only to a failed quarantined job and never repairs the world.
