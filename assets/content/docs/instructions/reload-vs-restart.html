Reloadable changes

Use /csx reload for global config.yml changes, new pack folders, corrected pack YAML, or schematic additions made before affected instances begin using them.

Reload guard

Reload is rejected while any paste job is queued, running, paused or finalizing. A paused instance retains its exact cursor and still blocks reload. Wait for every paste job to finish.

A rejected reload leaves the current runtime and scheduler in place. If loading a replacement configuration fails after schedulers stop, the plugin restores the previous config, packs, manager and schematic service, then restarts the previous scheduler.

Restart required

  • Replacing the CoreStructuresX JAR.
  • Replacing WorldEdit or FAWE.
  • Changing Paper or Minecraft version.
  • Recovering from startup dependency or classloading errors.
  • Performing a clean boot after broad configuration or pack changes.

Restart recovery

Normal shutdown persists every instance synchronously after flushing the ordered checkpoint writer. Startup reconstructs trusted jobs only when fingerprints, transforms and operation counts match. Changed recovery inputs block the job and parent connector instead of pasting unverified content.
