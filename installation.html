Installation and first pack

Install the runtime, validate a pack, then start a controlled test.

CoreStructuresX requires Java 21+, Paper 1.21.11+, and a loaded WorldEdit or FastAsyncWorldEdit plugin.

Installation

Install and validate a pack

1. Install

Place the plugins

  1. Stop Paper.
  2. Install WorldEdit or FAWE.
  3. Put CoreStructuresX-2026.1.1.jar in plugins/.
  4. Start Paper and confirm config.yml and the bundled packs/csx_test_pack/ are created.

2. Prepare

Use or add a pack

Use the bundled csx_test_pack for an initial test, or create plugins/CoreStructuresX/packs/<pack-id>/ with pack.yml, structure.yml, groups.yml, optional commands.yml, and a schematics/ folder. Existing copies of csx_test_pack are never overwritten.

3. Validate

Fix every error

/csx reload
/csx validate
/csx packs list

Do not start a pack while validation reports errors.

4. Test

Start manually

/csx start <pack-id>
/csx instances list
/csx instance info <instance-id>

Start in a controlled world and back up data/instances/ before large production tests.

Runtime layout

Keep definitions and live instance state separate.

plugins/CoreStructuresX/
|-- config.yml
|-- packs/
|   |-- csx_test_pack/
|   |   `-- bundled example files
|   `-- <pack-id>/
|       |-- pack.yml
|       |-- structure.yml
|       |-- groups.yml
|       |-- commands.yml
|       `-- schematics/*.schem
`-- data/instances/*.json
