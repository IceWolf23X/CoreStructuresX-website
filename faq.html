Frequently asked questions

Diagnose dependencies, packs, placement, and persisted state.

Use /csx validate before every first start and /csx instance info when a running instance stops expanding.

Why does the plugin disable on startup?

Confirm Java 21+, a compatible Paper build, and WorldEdit or FAWE. If the schematic API is unavailable, install the dependency and restart Paper.

Why is my pack not listed?

The folder must be under plugins/CoreStructuresX/packs/, contain pack.yml, use a valid unique pack id, and reference files that exist. Run /csx validate and /csx packs list.

Does every schematic need an ORIGIN sign?

No. With the default validation.require-origin: false, a schematic without ORIGIN uses its saved WorldEdit/FAWE clipboard origin. More than one ORIGIN marker is invalid.

Why does a structure start but not expand?

Inspect its state, open connectors, blocked reason, generated count, generation mode, automatic TPS/MSPT gates, and proximity radii. In proximity mode, the player must be in the same world and the specific connector must still be open.

Why was a candidate rejected for overlap?

Its transformed bounds intersect a generated module or pending job. Move markers, shrink the schematic, add fallback or endpoint groups, or carefully configure the optional double-pass block check.

What does BLOCKED mean?

At least one connector cannot be resolved. Validate the pack, inspect the recorded reason, and fix missing candidates, fallback/closing groups, overlap failures, or block-check failures.

Can I reload while a structure is expanding?

No. Pause affected instances and wait for paste jobs to finish before reloading pack or global YAML. Restart after replacing the plugin, WorldEdit/FAWE, or the Paper version.

What should I do with corrupt instance JSON?

Stop the server, back up data/instances/, then repair the file or move it aside. CoreStructuresX does not automatically delete corrupt persistence data.
