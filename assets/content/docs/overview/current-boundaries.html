Supported runtime boundary

  • Java 21 or newer.
  • Paper 1.21.11 or newer as the maintained documented requirement.
  • WorldEdit or FastAsyncWorldEdit installed and loaded.
  • WorldEdit Bukkit 7.4.3 is the current compile target; FAWE has no pinned Maven version in this project.

These are source and documentation facts for version 2026.1.1. They are not a guarantee for every future Paper, WorldEdit or FAWE build.

Manual start only

CoreStructuresX does not hook biome generation, chunk generation, world-seed distribution or random terrain placement. Every instance begins through an administrator command.

Not supported in v1

  • Folia scheduling.
  • Destructive module backtracking.
  • Storage types other than local JSON.
  • Paste modes other than chunked jobs.
  • Automatic migration of an administrator's existing YAML to newly added defaults.

Operational expectation

CoreStructuresX is under active development. Test updates and packs in an isolated environment, back up worlds, pack files, configuration and instance JSON, and review release notes before replacing a JAR.
