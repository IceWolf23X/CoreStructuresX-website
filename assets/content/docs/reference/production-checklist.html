Runtime

  • Paper starts cleanly with Java 21+ and a loaded WorldEdit or FAWE provider.
  • The exact Paper/provider combination has been tested with this plugin version.
  • Worlds, plugin data and pack sources have a tested backup and restore path.

Pack

  • /csx validate reports zero errors.
  • Every referenced schematic exists inside the configured folder.
  • Every reachable connector group has a finite endpoint route.
  • Fallback and endpoint-only closing groups have been exercised.
  • Every rotation preserves intended block states, signs, inventories, spawners, skulls, banners and lecterns.
  • Optional entities are tested on the target Paper/provider build before paste-entities is enabled.

Limits and performance

  • Module, radius and open-connector caps fit the intended largest structure.
  • Global axis, volume and chunk-footprint limits accept production schematics without allowing accidental huge inputs.
  • Block/time/job/chunk-load budgets have been measured with loaded and unloaded chunks.
  • TPS/MSPT pause and resume behavior is observed under load.
  • High-branching lookahead stops inside its configured node/time bounds.

Persistence and recovery

  • Automatic and proximity instances survive a normal restart.
  • Interrupted trusted phased jobs resume from persisted cursors.
  • Connectors, triggers and command UUIDs remain present after restart.
  • Rolling backup recovery and the manual stop/back-up/repair procedure are understood.
  • Clear-footprint is restricted to operators who can inspect the exact failed region.

Access

  • Start and instance-management permissions are limited to trusted administrators.
  • Pack authors understand that COMMAND markers execute as console.
