Purpose

config.yml owns the global pack/storage folders, marker contract, validation policy, checkpoint cadence, shared paste budgets, schematic limits, bounded caches, lookahead budget and TPS/MSPT governor.

Current bundled default

settings and packs

  • config-version must be 1.
  • settings.debug enables global diagnostic logging.
  • packs.folder is resolved below the plugin data folder; administrator-configured external roots are trusted only when explicitly configured and accessible.

markers

  • header defaults to [CSX].
  • case-insensitive-header defaults to true.
  • replacements.ORIGIN, CONNECTOR and COMMAND must name Bukkit block materials.

storage

  • type must be JSON.
  • save-connectors and save-triggers must remain true in v1.
  • checkpoint-interval-ticks and checkpoint-operations must each be at least 1.
  • force-at-phase-boundaries requests a checkpoint at paste phase transitions.

validation

  • strict rejects unknown fixed keys with the exact YAML path.
  • require-origin rejects missing ORIGIN markers when true; false uses the saved clipboard origin and reports a strict-mode warning.
  • require-all-connectors-resolvable requires every reachable connector group to have a finite endpoint path.

performance.paste

Only CHUNKED is supported. max-blocks-per-tick, max-milliseconds-per-tick, per-job-slice, max-active-jobs and max-chunk-loads-per-tick are shared global budgets. Every value must be positive and the per-job slice cannot exceed the block budget.

performance.schematics

max-axis, max-volume and max-chunks reject oversized source/candidate geometry with overflow-safe checks. Chunk count uses the complete transformed bounding-box footprint.

performance.schematic-cache

Compiled sources and transformed templates have independent entry and logical-weight bounds. warmup-templates: false compiles variants lazily. Enabling warmup checks all referenced rotations at load time but increases startup work; the same bounds still apply.

performance.lookahead

max-simulation-nodes and max-milliseconds bound each dry-run search. Budget exhaustion rejects that candidate instead of continuing unbounded work.

performance.stability

TPS and MSPT thresholds use hysteresis. Resume TPS must be at least the pause TPS, resume MSPT must be no greater than pause MSPT, and both the sampling interval and stable-sample count must be positive.

Upgrade note

Existing server YAML is not merged with newly bundled defaults. Compare the installed file with this current snapshot after each update and add keys deliberately.
