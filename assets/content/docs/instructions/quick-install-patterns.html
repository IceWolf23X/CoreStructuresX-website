Paper server

  1. Stop Paper.
  2. Install WorldEdit or FastAsyncWorldEdit.
  3. Place CoreStructuresX-2026.1.1.jar in plugins/.
  4. Start Paper once.
  5. Confirm plugins/CoreStructuresX/config.yml and packs/csx_test_pack/ were created.

First validation

/csx validate
/csx packs list

Fix every error before starting an instance. Warnings about an omitted ORIGIN mean the saved schematic clipboard origin will be used; confirm that position is intentional.

Controlled start

Back up the test world and instance folder, choose an isolated area, then start the bundled pack:

/csx start csx_test_pack
/csx instances list
/csx instance info <instance-id>

A console sender must provide the world, integer coordinates and cardinal facing:

/csx start csx_test_pack world 100 64 100 SOUTH

Restart test

After a controlled placement, stop Paper normally and start it again. Confirm the instance loads, connectors and triggers remain present, and any trusted interrupted job resumes only when its recorded pack, schematic, recipe, transform and operation counts still match.
