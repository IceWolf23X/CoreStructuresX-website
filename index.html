Validated packs, controlled expansion

Build modular structures without world-generation hooks.

CoreStructuresX starts structures only when an administrator asks it to. It pastes marked WorldEdit or FAWE schematics in controlled jobs, saves connectors and triggers to JSON, and expands each instance in automatic or player-proximity mode.

Install and prepare a packExplore features
  • Java 21+
  • Paper 1.21.11+
  • WorldEdit or FAWE
  • Manual start only

Designed for deliberate generation

Server owners stay in control of when, where, and how structures grow.

Manual starts

Use /csx start with a pack id and optional group, world position, facing, mode override, or debug output.

Recoverable instances

Atomic, versioned JSON stores modules, connectors, triggers, commands, paste phases, checksums, and cursors so trusted partial jobs can resume after restart.

Global placement safety

World-wide module and pending-job bounds prevent different instances from overlapping. Projected limits, block checks, bounded lookahead, fallbacks, and endpoint-only closing groups constrain every candidate.

Shared stability controls

Global block, NBT, entity, chunk-load, and time budgets combine with chunk tickets and a hysteretic TPS/MSPT governor across automatic and proximity jobs.
