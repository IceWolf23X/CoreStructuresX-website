Validated packs, controlled expansion

Build modular structures without world-generation hooks.

CoreStructuresX starts structures only when an administrator asks it to. It pastes marked WorldEdit or FAWE schematics in controlled jobs, saves connectors and triggers to JSON, and expands each instance in automatic or player-proximity mode.

  • Java 21+
  • Paper 1.21.11+
  • WorldEdit or FAWE
  • Manual start only

Designed for deliberate generation

Server owners stay in control of when, where, and how structures grow.

Manual starts

Use /csx start with a pack id and optional group, world position, facing, mode override, or debug output.

Persistent instances

Generated modules, connectors, triggers, commands, bounds, and state are stored in JSON rather than inferred from marker signs after restart.

Safety checks

Strict pack validation, transformed bounding boxes, overlap rejection, optional block whitelists, lookahead, fallbacks, and closing groups prevent uncontrolled placement.

Stability controls

Chunked pastes, per-instance job limits, TPS/MSPT gates, sample thresholds, and automatic delays keep expansion bounded.

Start with validation

Prepare a pack, run /csx validate, then start a test instance.
