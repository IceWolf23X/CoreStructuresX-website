Header

Every marker begins with [CSX] on line 1. Header matching is case-insensitive by default. Supported line-2 types are exactly ORIGIN, CONNECTOR and COMMAND.

ORIGIN

[CSX]
ORIGIN

Use zero or one ORIGIN. Zero uses the saved schematic clipboard origin when validation.require-origin is false. More than one is invalid. The marker block is replaced during paste.

CONNECTOR

[CSX]
CONNECTOR
<group-id>
<optional-radius>

Line 3 names a group from groups.yml. Optional line 4 is a positive player-proximity radius. A blank line uses the pack default; a nonblank zero, negative or malformed value is invalid. The sign facing determines the expansion direction.

COMMAND

[CSX]
COMMAND
<command-group-id>
<optional-radius>

Line 3 names a group from commands.yml. In automatic mode the command is considered after durable module finalization. In proximity mode it waits for the saved trigger. The transformed marker position supplies command coordinates.

Authoring rules

  • Do not use aliases such as CONN, ENTRY, EXIT or NODE.
  • Do not encode dimensions, directions, coordinates or rotation in sign text.
  • Marker replacement material is global unless the selected group entry overrides it.
  • In proximity mode, every connector needs an explicit radius or a positive pack default.
