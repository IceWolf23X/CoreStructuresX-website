CoreStructuresX 2026.1.1 is a Paper plugin for manual-start modular structures. Administrators assemble structure packs from WorldEdit or FastAsyncWorldEdit schematics, validate the pack, and choose the location and facing of the first module.

What it does

  • Loads versioned YAML pack definitions and referenced .schem modules.
  • Reads [CSX] ORIGIN, CONNECTOR and COMMAND marker signs.
  • Selects weighted schematic candidates, then tries configured fallback and closing groups.
  • Expands automatically or from a saved player-proximity trigger.
  • Applies world-wide overlap checks, optional block whitelists, projected hard limits and bounded lookahead.
  • Persists modules, connectors, triggers, commands and paste progress as data-version-5 JSON.

Current stack

The build targets Java 21, Paper API 1.21.11 and WorldEdit Bukkit 7.4.3. At runtime, install WorldEdit or FastAsyncWorldEdit. Those coordinates describe the current build boundary; test the exact Paper and schematic-provider builds used by your server.
