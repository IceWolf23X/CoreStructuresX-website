Requirements

  • Java 21+.
  • Paper 1.21.11+.
  • CoreStructuresX 2026.1.1.
  • WorldEdit or FastAsyncWorldEdit installed and loaded.
  • A permission manager when operator-only defaults are not appropriate.

Back up before world mutation

Before testing a new pack or plugin update, back up the affected worlds and the complete plugins/CoreStructuresX/ directory. Keep configuration, pack YAML, schematics and data/instances/ together in the recovery set.

Trust boundary

Only trusted administrators should author packs or receive start permission. Schematics modify world blocks and optional entities; COMMAND markers dispatch server-console commands after durable placement.

Validation boundary

Validation catches unsupported keys and modes, unsafe paths, missing references, marker defects, unresolved connector graphs and configured size limits. It cannot prove visual correctness, production performance, plugin interoperability or every runtime world condition.

Existing YAML is not auto-merged

When a plugin update adds bundled keys, the existing server file is left unchanged. Compare it with the documented current default and add new settings deliberately.
