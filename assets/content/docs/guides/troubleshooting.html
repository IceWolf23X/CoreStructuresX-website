Plugin disables on startup

Confirm Java 21+, a compatible Paper build, and a loaded WorldEdit or FastAsyncWorldEdit provider. When the API is absent, CoreStructuresX logs the exact dependency error and disables itself safely.

Pack is not listed

Confirm the folder is a normal direct child of packs/, contains pack.yml, uses a unique safe id, and does not escape through configured paths or filesystem links. Run validation and inspect the complete path in each diagnostic.

Schematic fails validation

Check provider readability, configured axis/volume/chunk limits, ORIGIN count, connector/command group ids, positive proximity radii and referenced material names.

Structure starts but does not expand

Use /csx instance info. Inspect instance state, active jobs, open/blocked connectors, mode, generated count and quarantine count. Automatic mode may be waiting for stable TPS/MSPT samples or job delay. Proximity mode requires the player in the same world and the specific trigger active.

Candidate rejected for overlap

Its transformed bounds intersect a generated module, pending job or persisted failed footprint. Move markers, shrink the schematic, add fallback/endpoint candidates, or enable a carefully bounded double pass with block checking. Pending jobs cannot be bypassed.

Instance is BLOCKED

At least one connector could not be resolved. Read the recorded reason and repair the candidate set, fallback/closing graph, overlap geometry, whitelist or lookahead constraint. CoreStructuresX does not delete prior modules to retry.

JSON cannot be loaded

Stop Paper and back up the complete instances folder. The loader first tries the rolling .json.bak. If recovery cannot be completed, preserve the primary and backup, inspect the error, and repair or move the broken canonical file aside. Do not edit live state.

Failed footprint remains reserved

Inspect or repair the exact world region shown by /csx instance info. Only then use /csx instance clear-footprint <instance-id> <job-id>. The command releases the collision reservation; it does not inspect or fix blocks or entities.
