Purpose

structure.yml owns start, placement, generation mode, hard limits, completion, spatial checks and per-pack paste behavior.

Bundled example

Identity and start

  • structure-version must be 1.
  • id must equal pack.yml.id.
  • enabled defaults to true.
  • start.mode must be MANUAL; start.group must exist.

Placement

native-facing accepts NORTH, EAST, SOUTH or WEST. offset.forward, left and right are non-negative; up may be signed. Legacy height remains an alias for up.

Generation

  • mode: AUTOMATIC or PLAYER_PROXIMITY.
  • Automatic order supports NEAREST_TO_ORIGIN then FIFO; job-delay is non-negative ticks.
  • Lookahead depth is 0–10 and at least 1 when enabled; policy is ALL_CONNECTORS or ANY_CONNECTOR.
  • backtrack-on-blocked must remain false.
  • Proximity check interval accepts ticks such as 20t; default radius is non-negative.

Limits and completion

max-modules, max-radius and max-open-connectors must be at least 1. require-all-connectors-resolved must remain true. enter-closing-when-limits-reached controls whether remaining connectors try closing groups.

Space checks

Overlap mode is SCHEMATIC_BOUNDING_BOX; padding is non-negative. Double pass requires enabled WHITELIST block checking. Replaceable materials and post-paste replacements must be valid Bukkit blocks.

Per-pack paste

Mode must be CHUNKED. The pack block budget and per-instance active-job limit must be positive. paste-air controls source air; paste-entities opts into schematic entity placement.
