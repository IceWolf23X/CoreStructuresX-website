Purpose

pack.yml names one structure pack and points to its structure, group, command and schematic resources.

Bundled example

Schema

KeyRule
pack-versionMust be 1.
idRequired safe id. Duplicate ids disable every duplicate definition.
nameDisplay name; defaults to id.
versionPack author's version string; defaults to 1.0.0.
authorDefaults to unknown.
structureDefaults to structure.yml.
groupsDefaults to groups.yml.
commandsDefaults to commands.yml; file is optional until a COMMAND marker references a group.
schematics-folderDefaults to schematics.

Path safety

Every referenced path must be relative and remain inside the pack after normalization and real-path resolution. Absolute paths, parent traversal and external symbolic-link/junction/reparse targets are rejected.

Folder name

The folder may differ from id, but validation warns because matching names make administration clearer.
