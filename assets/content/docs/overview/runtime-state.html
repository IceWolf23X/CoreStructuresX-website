Instances

An instance owns one structure origin, selected mode, generated modules, connectors, triggers, command records and paste journals. Its persisted id is also its canonical JSON filename.

Instance states

CREATED
EXPANDING
AUTO_EXPANDING
PAUSED
STOPPED
CLOSING
COMPLETED
BLOCKED
FAILED

PAUSED preserves active progress. STOPPED is terminal and accepted only without an active or recoverable job. COMPLETED requires every connector to be used or closed and no active job.

Connector states

OPEN
PROCESSING
USED
CLOSED
BLOCKED

Every PROCESSING connector must correspond to exactly one recoverable child job, and every recoverable child job must reference its PROCESSING parent connector.

Trigger states

ACTIVE
DISABLED
EXPIRED

Triggers are persisted independently from marker signs, so proximity behavior survives marker replacement and restart.

Durable finalization

FINALIZING is a job phase, not a public instance state. The detached final state is committed before new modules, connectors, triggers, completion or immediate command dispatch become visible to the live runtime.
