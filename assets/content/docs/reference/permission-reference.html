Umbrella permission

corestructuresx.admin

This node grants every administrative child and defaults to operators.

Individual permissions

corestructuresx.admin.reload
corestructuresx.admin.validate
corestructuresx.admin.packs
corestructuresx.admin.start
corestructuresx.admin.instances

Every child also defaults to operators. Each command handler accepts either its specific child or the umbrella permission.

Recommended split

Builders may receive validation and pack listing without start or instance mutation. Restrict start, pause/resume/stop and clear-footprint to trusted administrators because they can paste content or change live recovery reservations.

lp group builder permission set corestructuresx.admin.validate true
lp group builder permission set corestructuresx.admin.packs true
lp group admin permission set corestructuresx.admin true

Command marker trust

Permission nodes control the CoreStructuresX admin command. They do not sandbox console commands authored inside a pack. Limit filesystem and pack-authoring access separately.
